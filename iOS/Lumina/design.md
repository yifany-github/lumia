2. 粒子图片预览组件
这是最重要的视觉功能。

请实现一个 ParticleImage 组件：
- 输入：imageUrl、config。
- 把图片绘制到 canvas，然后按一定间隔采样像素。
- 每个采样像素生成一个粒子。
- 粒子保留原始颜色。
- 粒子根据图片形状排列，整体看起来像由彩色星尘组成的照片。
- 粒子有轻微漂浮、呼吸、流动动画。
- 鼠标移动到图片附近时，粒子有轻微散开或跟随效果。
- 支持参数：
  - dispersion：粒子扩散程度
  - particleSize：粒子大小
  - flowSpeed：流动速度
  - depth：伪 3D 深度
  - danceStrength：粒子抖动强度
  - rotation：旋转角度，可支持 0 / 90 / 180 / 270
- 粒子数量需要控制，保证性能。
- 在移动端也要能运行，必要时降低采样密度。

粒子效果逻辑建议：
- 将图片绘制到隐藏 canvas。
- 每隔 4~8 像素采样一个点。
- 忽略透明度太低或过暗的像素，或者降低它们的 alpha。
- 每个粒子包含：
  - baseX / baseY：原始位置
  - x / y：当前显示位置
  - color：像素颜色
  - size：粒子大小
  - randomOffset：随机偏移
  - depth：随机深度
  - velocity：轻微速度
- 每帧通过 requestAnimationFrame 更新。
- 使用 sin / cos / noise 模拟粒子漂浮。
- 粒子最终位置 = base position + flow offset + dispersion offset + mouse interaction。
- canvas 背景透明，外层容器用暗色渐变。
